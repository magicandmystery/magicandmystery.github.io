Description

Draft dice and use special abilities in Sagrada to carefully construct your stained glass window masterpiece.

Each player builds a stained glass window by creating a grid of dice on their player board

Each board has some restrictions on which color or number of die can be placed there. Dice of the same number or color may never be placed next to each other.

Dice are drafted in player order, with the start player rotating each round, snaking back around after the last player drafts two dice.

Scoring is variable per game based on achieving various patterns and varieties of placement...as well as bonus points for high numbered dice of a particular hidden color goal.

Special abilities (cards) can be used to help you break the rules by spending skill tokens; once a tool is used, it then requires more skill tokens for the other players to use them.

The player with the highest scoring window wins!
